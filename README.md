# 🏋️ Personal Gym Tracker

### Python & Software Development Project

## 📌 Project Overview

Personal Gym Tracker is a fitness tracking application built using Python. Its purpose is to help users record gym workouts, monitor strength improvements, track bodyweight, and measure overall fitness progress.

This project is part of my journey to improve my programming and software development skills through hands-on experience.

The application will begin as a simple Python program and gradually evolve into a fully functional fitness tracking website.

## 🎯 Project Goals

- Record exercises, sets, reps, and weights.
- Calculate workout volume and performance.
- Monitor strength improvements and personal records (PRs).
- Track bodyweight and fitness goals.
- Analyze workout consistency and progress.
- Build an accessible fitness tracking website.

## 💪 Example Workout

**Exercise:** Dumbbell Bench Press

| Measurement | Value |
|---|---|
| Weight | 70 lbs per dumbbell |
| Sets | 4 |
| Reps per set | 10 |
| Total reps | 40 |
| Total volume | 5,600 lbs |

**Calculations:**

Total Reps = Sets × Reps

4 × 10 = 40 reps

Total Volume = Weight × 2 Dumbbells × Sets × Reps

70 × 2 × 4 × 10 = 5,600 lbs

**Expected output:**

```text
Exercise: Dumbbell Bench Press
Weight: 70 lbs per dumbbell
Sets: 4
Reps: 10

Total Reps: 40
Total Volume: 5600 lbs

Workout saved successfully!
```
